# Contributing

Read the [Pets contribution docs](https://pets-registry.github.io/pets/) for the complete fork, branch, validation, commit, push, and pull-request workflow.

For a new Pet, create the package in its own repository with the Kirn command `kirn new pets <petname>`. Do not hand-edit `registry.toml` to register package content unless a maintainer specifically requests a registry change.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md), [Accessibility](ACCESSIBILITY.md), and [Security Policy](SECURITY.md).
