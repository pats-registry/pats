## Overview

The Pats repository is the source-backed registry index for Kirn package discovery. Pat source code and release workflows live in each developer’s own repository; this repository provides the registry metadata, contribution rules, and publishing guidance.

## Local development

This repository contains a static website or documentation site. Follow the repository-specific instructions below.

~~~bash
cd docs-site
npm install
npm run docs:dev
~~~

For VitePress repositories, open the local URL shown by the development server. For static websites, open <http://localhost:8000/>.
