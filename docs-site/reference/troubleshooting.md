# Troubleshooting

## Git says the branch already exists

Switch to a different branch name or delete the local branch only if you no longer need its work:

```bash
git switch -c docs/pats-workflow
```

## Push is rejected

Fetch the latest upstream changes and rebase your feature branch:

```bash
git fetch upstream
git rebase upstream/main
git push --force-with-lease
```

Use `--force-with-lease`, not plain `--force`, when updating a branch after a rebase.

## The Pat build fails

Run `kirn test` first, then `kirn build pats`. Read the first error, check the manifest, and compare your project with the scaffold generated by `kirn new pats`.

## The release did not run

Check that:

- The workflow is in the Pat repository at `.github/workflows/kirn-pats-release.yml`.
- The tag starts with `v`.
- The tag was pushed to GitHub.
- Actions are enabled for the repository.
- The workflow has permission to create releases.

## I changed registry.toml to add my Pat

Stop and revert that change unless a maintainer specifically requested it. The current repository policy says the index is populated through the release and maintainer workflow, not by hand.
